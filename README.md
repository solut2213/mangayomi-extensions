# Mangayomi Extensions

Custom extension repository for [Mangayomi](https://github.com/kodjodevf/mangayomi).

## Available Extensions

| Source | Type | Language | Version | Notes |
| :--- | :---: | :---: | :---: | :--- |
| **Fenrir Realm** | Novel | English (`en`) | 1.0.0 | High-performance TipTap AST reader support, 890+ chapters |

---

## How to Add to Mangayomi

1. Open **Mangayomi**.
2. Go to **More** $\rightarrow$ **Settings** $\rightarrow$ **Browse** $\rightarrow$ **Novel Extension Repositories**.
3. Tap **Add Repository** and enter:
   ```
   https://raw.githubusercontent.com/solut2213/mangayomi-extensions/main/index.json
   ```
4. Return to **Browse** $\rightarrow$ **Novels**, find **Fenrir Realm**, and tap **Install**.
